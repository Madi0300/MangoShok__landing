# 🥭 Манго&Шок — Лендинг-страница

Демонстрационный лендинг для кондитерского бренда **«Манго&Шок»** — производителя манго в премиальном бельгийском шоколаде ручной работы.

## 🔍 О проекте

Это одностраничный сайт (лендинг), разработанный с нуля под ключ. Цель страницы — представить продукт, вызвать доверие у покупателя и побудить его к заказу.

## ✅ Что реализовано

- **Шапка** — логотип, навигация с плавной прокруткой, мобильное меню
- **Главный экран (Hero)** — заголовок, описание продукта, призыв к действию
- **Преимущества** — блок с отличительными особенностями бренда
- **Ассортимент** — карточки товаров с фото, описанием и ценой
- **Процесс производства** — пошаговое описание с анимацией
- **Калькулятор заказа** — интерактивный расчёт стоимости в реальном времени
- **Отзывы** — блок с клиентскими отзывами
- **FAQ** — блок часто задаваемых вопросов с аккордеоном
- **Форма обратной связи** — контактная форма
- **Футер** — контакты, ссылки, соцсети

## 🛠 Стек технологий

| Технология | Описание |
|---|---|
| HTML5 | Семантическая разметка |
| CSS3 | Кастомные стили, анимации, адаптив |
| JavaScript | Интерактивность, калькулятор, модалки |

## 📱 Особенности

- Полностью **адаптивный** дизайн (мобильные, планшеты, десктоп)
- **Плавные анимации** при скролле
- **Интерактивный калькулятор** стоимости заказа
- Оптимизирован под **SEO** (мета-теги, семантика, Open Graph)
- Без использования сторонних CSS-фреймворков — чистый код
